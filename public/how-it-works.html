How Gilded Bay works

Gilded Bay keeps one short list for your whole team, so everyone sees the same five things first.

  1. Add an item to the shared list.
  2. Mark it done when it is finished.
  3. Watch the newest five appear on the home page.

The list refreshes whenever the page loads, so there is nothing to sync and nothing to install before you start.
